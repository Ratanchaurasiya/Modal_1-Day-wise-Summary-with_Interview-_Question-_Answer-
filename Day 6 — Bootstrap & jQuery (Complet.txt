# Easy Level Bootstrap Interview Questions

## 1. What is Bootstrap?

### Answer:

Bootstrap is a popular frontend framework used to create responsive and modern websites quickly.

It provides:

* Predefined CSS classes
* Responsive grid system
* Ready-made components
* Faster web development

### Example:

```html id="q68bva"
<button class="btn btn-primary">
    Click Me
</button>
```

---

# 2. Why is Bootstrap used?

### Answer:

Bootstrap is used to:

* Save development time
* Create responsive websites
* Reduce CSS coding
* Make websites mobile-friendly

### Advantages:

1. Easy to use
2. Responsive design
3. Cross-browser support
4. Modern UI components

---

# 3. What is CDN in Bootstrap?

### Answer:

CDN means **Content Delivery Network**.

It is used to load Bootstrap files directly from the internet without downloading them.

### Example:

```html id="rzs59r"
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
```

---

# 4. What is the Bootstrap Grid System?

### Answer:

Bootstrap grid system divides webpage into **12 columns**.

It helps create responsive layouts.

### Example:

```html id="itk5qq"
<div class="row">

    <div class="col-6">
        Left
    </div>

    <div class="col-6">
        Right
    </div>

</div>
```

# 5. What is Responsive Web Design?

### Answer:

Responsive design means the website automatically adjusts according to screen size like:

* Mobile
* Tablet
* Laptop
* Desktop

Bootstrap uses breakpoints for responsive design.

# Easy Level jQuery Questions

---

# 1. What is jQuery?

### Answer:

jQuery is a JavaScript library used to simplify JavaScript coding.

### Features:

* DOM manipulation
* Animation
* Event handling
* AJAX support

---

# 2. Why use jQuery?

### Answer:

jQuery reduces JavaScript code and makes development easier.

### Benefits:

* Easy syntax
* Fast coding
* Cross-browser support

---

# 3. What is DOM?

### Answer:

DOM means **Document Object Model**.

It represents webpage structure as objects.

jQuery manipulates DOM elements easily.

---

# 4. What does `$` mean in jQuery?

### Answer:

`$` is shortcut for jQuery.

### Example:

```javascript id="6oaj7j"
$("#demo").hide();
```

---

# 5. What is document.ready()?

### Answer:

It ensures webpage loads completely before running jQuery code.

### Example:

```javascript id="mth2uy"
$(document).ready(function(){

    alert("Page Loaded");

});
```

---

# 6. Difference between text() and html()?

### Answer:

| text()     | html()       |

```javascript id="1f50wt"

$("#demo").html("<h1>Hello</h1>");
```

# 7. What is event handling in jQuery?

Handling user actions like:

* Click

* Keypress


# 2. Explain fade effects in jQuery.

### Answer:

Using multiple methods in one line.

### Example:

