# 1. React.js Introduction

## React Kya Hai?

React ek JavaScript library hai jo UI (User Interface) banane ke liye use hoti hai.

React ka use:

* Dynamic websites
* Single Page Applications
* Frontend development
* Fast UI rendering

me hota hai.

---

# 2. React Ki Important Features

## Component-Based Architecture

React me UI ko small reusable components me divide kiya jata hai.

Example:

```jsx
function Header() {
  return <h1>Hello</h1>;
}
```

Benefits:

* Reusable code
* Easy maintenance
* Better readability

---

## Virtual DOM

React directly browser DOM ko update nahi karta.

Flow:

```text
User Action
   ↓
Virtual DOM Update
   ↓
Compare Changes
   ↓
Real DOM Update
```

Benefits:

* Faster rendering
* Better performance

---

## Single Page Application (SPA)

React me page reload nahi hota.

Sirf required content update hota hai.

Benefits:

* Fast user experience
* Smooth navigation

---

# 3. DOM vs Virtual DOM

| DOM                    | Virtual DOM      |
| ---------------------- | ---------------- |
| Slow                   | Fast             |
| Real Browser Structure | Copy of DOM      |
| Full update            | Partial update   |
| Less optimized         | Highly optimized |

---

# 16. Important React Files

## App.jsx

Main component file.

Example:

```jsx
function App() {
  return (
    <div>
      <h1>Hello Ratan</h1>
    </div>
  );
}

export default App;
```

---

## main.jsx

React app render karta hai.

Example:

```jsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App'

ReactDOM.createRoot(document.getElementById('root')).render(
  <App />
)
```

# Advanced Level Questions

## 21. Explain the React rendering process.

Answer:

```text id="5e5ykk"
State Change
   ↓
Virtual DOM Update
   ↓
Diffing Process
   ↓
Detect Changes
   ↓
Update Real DOM
```

---

## 22. What is the Diffing Algorithm in React?

Answer:

React compares the old Virtual DOM with the new Virtual DOM to detect changes.

---

## 23. Why is Virtual DOM efficient?

Answer:

Because React updates only the changed elements instead of reloading the whole page.

---
