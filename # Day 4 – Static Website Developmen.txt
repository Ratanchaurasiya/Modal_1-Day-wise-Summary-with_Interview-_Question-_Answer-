# Day 4 Interview Questions and Answers

# Basic Level Questions

## 1. What is a static website?

### Answer:

A static website is a website where the content remains fixed and does not change automatically. These websites are created using HTML, CSS, and JavaScript.

All users see the same content because there is no database or server-side processing involved.

### Features:

* Fast loading speed
* Simple design
* Easy hosting
* No database required

---

## 2. Why do we create separate HTML files in a website project?

### Answer:

Separate HTML files help organize the project properly. Each page has its own responsibility.

### Example:

* `login.html` for login page
* `register.html` for registration page
* `about.html` for about section

### Advantages:

* Better organization
* Easier maintenance
* Cleaner code structure
* Faster development

---

## 3. What is the purpose of `header.html` and `footer.html`?

### Answer:

`header.html` stores the navigation bar and top section of the website.

`footer.html` stores footer content like copyright, links, and contact information.

Instead of writing the same code repeatedly on every page, these files are reused.

### Benefits:

* Code reusability
* Consistent design
* Easier updates

---

## 4. What is the use of the `fetch()` method in JavaScript?

### Answer:

The `fetch()` method is used to load external files or data dynamically without refreshing the webpage.

It sends a request to the server and receives the response asynchronously.

### Example:

```javascript id="q5n8pl"
fetch("header.html")
  .then(response => response.text())
  .then(data => {
    document.getElementById("header").innerHTML = data;
  });
```

### Advantages:

* Dynamic content loading
* Faster webpage updates
* Better user experience

---

## 5. What does `response.text()` do in fetch?

### Answer:

`response.text()` converts the fetched response into text format so it can be displayed on the webpage.

### Example:

```javascript id="k7x2de"
fetch("header.html")
  .then(response => response.text())
```

This helps convert raw response data into readable HTML content.

# Advanced Level Questions

## 11. Explain asynchronous behavior in JavaScript fetch.

### Answer:

`fetch()` works asynchronously, meaning JavaScript continues running other code while waiting for the server response.

This improves webpage performance because the browser does not freeze during loading.

### Advantages:

* Faster user experience
* Smooth webpage interaction
* Better performance

---

## 12. What is a Promise in JavaScript?

### Answer:

A Promise is an object that represents the future result of an asynchronous operation.

### Promise States:

1. Pending
2. Resolved
3. Rejected

### Example:

```javascript id="w9m5ks"
fetch("header.html")
  .then(response => response.text())
```

Promises help handle asynchronous tasks efficiently.

---

## 13. How does `.then()` work in fetch?

### Answer:

`.then()` is used to execute code after the fetch request is completed successfully.

### Example:

```javascript id="c8v4hy"
fetch("header.html")
  .then(response => response.text())
  .then(data => {
    console.log(data);
  });
```

It processes the response step-by-step.

---

## 14. How can we handle fetch errors using `.catch()`?

### Answer:

`.catch()` handles errors that occur during the fetch operation.

### Example:

```javascript id="a1t7qw"
fetch("header.html")
  .then(response => response.text())
  .then(data => {
    document.getElementById("header").innerHTML = data;
  })
  .catch(error => {
    console.log("Error loading file");
  });
```

### Benefits:

* Prevents application crashes
* Improves debugging
* Displays error messages properly

# Advanced Level Interview Questions and Answers – Day 4 Static Website Development

## 1. Explain asynchronous behavior in JavaScript fetch.

### Answer:

The `fetch()` method works asynchronously, which means JavaScript does not wait for the response before executing the next line of code. The browser continues running other tasks while the data is being loaded in the background.

This improves website performance and user experience because the webpage does not freeze while waiting for data.

### Example:

```javascript id="h7m2qa"
console.log("Start");

fetch("header.html")
  .then(response => response.text())
  .then(data => {
    console.log(data);
  });

console.log("End");
```

### Output:

```text id="x8q1wn"
Start
End
<header data appears later>
```

### Advantages:

* Faster webpage performance
* Smooth user interaction
* Non-blocking operations

---

## 2. What is a Promise in JavaScript?

### Answer:

A Promise is a JavaScript object used to handle asynchronous operations. It represents a future result that may complete successfully or fail.

### Promise States:

1. Pending → Operation is still running
2. Fulfilled → Operation completed successfully
3. Rejected → Operation failed

### Example:

```javascript id="q2m9de"
fetch("header.html")
  .then(response => response.text())
  .then(data => {
    console.log(data);
  });
```

### Importance of Promises:

* Handles asynchronous code properly
* Avoids callback nesting
* Improves code readability

---

## 3. Explain the role of `.then()` in fetch.

### Answer:

`.then()` is used to process the successful response returned by the `fetch()` method.

When fetch successfully loads a file, `.then()` executes the next block of code.

### Example:

```javascript id="t4v8ka"

  .then(response => response.text())
  .then(data => {
    document.getElementById("footer").innerHTML = data;
  });
```

### Working:

* First `.then()` converts response into text
* Second `.then()` displays the data on the webpage

## 8. What security issues can occur while using fetch?

### Answer:

Some security issues while using fetch include:

### 1. CORS Errors

CORS (Cross-Origin Resource Sharing) blocks requests from unauthorized domains.

### 2. Loading Untrusted Content

Loading unknown external files can create security risks.

### 3. Data Exposure

Sensitive information should not be exposed publicly.

### Prevention Methods:

* Use secure servers
* Validate inputs
* Restrict API access
* Use HTTPS
