# 1. Add Loading in Product Page

## What is Loading?

Loading means showing a message, spinner, or animation while data/products are being fetched from API or database.

Example:

* "Loading..."
* Spinner animation
* Skeleton loader

---

## HTML

```html
<div id="loader">
    Loading Products...
</div>

<div id="products"></div>
```

---

## JavaScript

```javascript
const loader = document.getElementById("loader");
const products = document.getElementById("products");

loader.style.display = "block";

setTimeout(() => {
    loader.style.display = "none";

    products.innerHTML = `
        <h2>Product 1</h2>
        <h2>Product 2</h2>
        <h2>Product 3</h2>
    `;
}, 3000);
```

---

## Explanation

| Code                | Meaning              |
| ------------------- | -------------------- |
| `getElementById()`  | Select element       |
| `display = "block"` | Show loader          |
| `setTimeout()`      | Delay execution      |
| `innerHTML`         | Add HTML dynamically |
| `display = "none"`  | Hide loader          |

# 8. Sort Function in Category/Product Page

## What is Sorting?

Sorting arranges products:

* Low to High price
* High to Low price
* A-Z
* Z-A

---

# Example Product Array

```javascript
const products = [
    {name: "Bag", price: 500},
    {name: "Shoes", price: 1000},
    {name: "Watch", price: 700}
];
```

---

# Sort Low to High

```javascript
products.sort((a, b) => a.price - b.price);

console.log(products);
```

---

# Sort High to Low

```javascript
products.sort((a, b) => b.price - a.price);

console.log(products);
```

---

# Explanation

| Code                | Meaning          |
| ------------------- | ---------------- |
| `sort()`            | Sort array       |
| `a.price - b.price` | Ascending order  |
| `b.price - a.price` | Descending order |

# Complete Product Filter + Sort Example

## HTML

```html
<select id="sort">
    <option value="low">Low to High</option>
    <option value="high">High to Low</option>
</select>

<button onclick="filterFashion()">Fashion</button>

<div id="output"></div>
```

---

## JavaScript

```javascript
const products = [
    {name: "Bag", category: "fashion", price: 500},
    {name: "Laptop", category: "electronics", price: 50000},
    {name: "Shoes", category: "fashion", price: 1500}
];

function display(data) {
    let result = "";

    data.forEach((item) => {
        result += `
            <h3>${item.name} - ${item.price}</h3>
        `;
    });

    document.getElementById("output").innerHTML = result;
}

display(products);

document.getElementById("sort").addEventListener("change", function() {

    if(this.value === "low") {
        products.sort((a,b) => a.price - b.price);
    } else {
        products.sort((a,b) => b.price - a.price);
    }

    display(products);
});

function filterFashion() {

    const filtered = products.filter((item) => {
        return item.category === "fashion";
    });

    display(filtered);
}
```

# 2. Explain Event Delegation in JavaScript

## Answer

Event Delegation means adding one event listener to a parent element instead of adding listeners to multiple child elements.

It improves:

* Performance
* Memory optimization
* Dynamic element handling

---

## Example

```html id="s6b8w8"
<ul id="list">
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>
```

```javascript id="qk9vmb"

    if(e.target.tagName === "LI"){
        console.log(e.target.innerText);
    }

});
```

---

## Benefits

✅ Better performance
✅ Less memory usage
✅ Handles dynamic elements automatically

# 4. Explain Debouncing in Search Filter

## Answer

Debouncing delays function execution until the user stops typing.

Used in:

* Search bars
* API requests
* Product filters

---

## Example

```javascript id="qk9lt5"
function debounce(func, delay){

    let timer;

    return function(){

        clearTimeout(timer);

        timer = setTimeout(() => {
            func();
        }, delay);

    };

}
```

---

## Why Important?

Without debounce:

* API calls happen many times

With debounce:

* Better performance
* Less server load
