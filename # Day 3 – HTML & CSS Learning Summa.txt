# Day 3 – HTML & CSS Learning Summary

Today we created a **static website** project named **Car Hubs**. In this project, we used different **semantic HTML elements** to structure the webpage properly. Semantic elements help make the website organized, readable, and SEO-friendly.

## Semantic Elements Used

* `<header>` → Used for the top section of the website.
* `<nav>` → Used for the navigation bar and menu links.
* `<section>` → Used to create different sections of the webpage.
* `<main>` → Used for the main content area.
* `<footer>` → Used for the footer section.

We also created a **navigation bar (Navbar)** to move between different sections of the website like Home, About, Cars, and Contact.

# Using External Header File

Today we learned how to use a separate HTML file for the header and load it dynamically using JavaScript.

We created:

* `header.html` → Contains navbar/header code.
* `index.html` → Main webpage file.

We used the following code to load the header file dynamically:

```javascript
fetch('header.html')
    .then(response => response.text())
    .then(data => {
        const headerContainer = document.querySelector('.navbar');

        if (headerContainer) {
            headerContainer.innerHTML = data;
        }
    })
    .catch(error => console.error('Error loading header:', error));
```

We also used:

```html
<div class="navbar"></div>

<section id="home" class="slider-container">
```

This code helps us insert the `header.html` file into the main webpage automatically. It makes the project cleaner and reusable because we can update the header in one file only.

# HTML Code Example

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Car Hubs</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <!-- Navbar Container -->
    <div class="navbar"></div>

    <!-- Home Section -->
    <section id="home" class="container">
        <div class="left-box">
            <h1>Welcome to Car Hubs</h1>
            <p>Best cars collection website.</p>
        </div>

        <div class="center-box">
            <h2>Center Content</h2>
        </div>

        <div class="right-box">
            <h2>Right Content</h2>
        </div>
    </section>

    <script>
        fetch('header.html')
            .then(response => response.text())
            .then(data => {
                const headerContainer = document.querySelector('.navbar');

                if (headerContainer) {
                    headerContainer.innerHTML = data;
                }
            })
            .catch(error => console.error('Error loading header:', error));
    </script>

</body>
</html>
```
